# A kanbanr board

This repository is a [kanbanr](https://github.com/startr-trade/kanbanr) board: the plan, the reasoning and the evidence for the work below, kept as plain YAML and markdown. kanbanr reads it and shows it as a board; you can read the files too.

## Projects

- `kanbanr`: kanbanr's own development board: every item with why it exists, its requirements and the tests that proved them — kanbanr is developed with kanbanr.

## See it as a board

1. Install kanbanr:

   ```sh
   # macOS and Linux
   curl -fsSL https://github.com/startr-trade/kanbanr/releases/latest/download/install.sh | sh
   ```

   ```powershell
   # Windows
   irm https://github.com/startr-trade/kanbanr/releases/latest/download/install.ps1 | iex
   ```

   Or, with a Rust toolchain: `cargo install --locked --git https://github.com/startr-trade/kanbanr kanbanr-cli`

2. Clone this repository, and start the monitor over it:

   ```sh
   git clone <this repository's URL> board
   kanbanr serve --data-dir board
   ```

3. Open <http://127.0.0.1:8080>. The monitor is read-only unless it was started with `--allow-writes`.

## Or in the terminal

```sh
kanbanr board --data-dir board --project kanbanr
kanbanr feature show <CODE> --data-dir board --project kanbanr
```

## Changing it

kanbanr is the one writer: change the board with the `kanbanr` command (or the monitor started with `--allow-writes`), never by editing the YAML by hand. Changes reach others through this repository's git remote.

More: the [kanbanr guide](https://startr-trade.github.io/kanbanr/).
