# Getting started

![kanbanr architecture](getting-started-diagram.png)

```bash
make install
kanbanr init my-app --author "You" --email you@example.com
kanbanr serve --ui-dir web/dist
```

The image above lives in **this** folder (`guides/`) and is referenced by its bare name — relative
image names resolve per-folder, so they're meaningful in every docs folder.
