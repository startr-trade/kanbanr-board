# v0.2.1 — Fixes after 0.2.0

_Released 2026-10-21._

## What shipped

### FEAT-209 — A diagram opened from the book draws as black boxes

A diagram opened full size from the book draws in the reader's theme, as it does in the page

- WHEN a reader opens a diagram from the book, THE SYSTEM SHALL show it with the shapes, labels and background colours of the theme it was opened from

### FEAT-210 — The release's install check misreads the monitor's relative bundle path

A release's install check confirms the installed binary serves its monitor, whether the monitor names its bundle by an absolute or a relative path

- WHEN a published release is verified, THE SYSTEM SHALL find the bundle the served index.html names, by an absolute or a relative path, and fetch it

### FEAT-211 — Release 0.2.1

kanbanr 0.2.1 can be cut and released, carrying the two fixes found after 0.2.0, with notes that say what they fix

- WHEN v0.2.1 is tagged, THE SYSTEM SHALL pass the release workflow's checks that the tag, the workspace version, the extension version and the release notes agree
- THE SYSTEM SHALL continue to pass its test suite and docs checks after the version change
